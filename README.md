# SaathiSignal — Safe Handoff Network

## Overview
SaathiSignal is a privacy-first, consent-based platform designed to connect people experiencing domestic abuse or coercive control with verified support organisations.

## Problem Statement
Survivors may face device monitoring, limited privacy, fear of retaliation, and difficulty finding appropriate support services. Sending a request does not guarantee that a support organisation has received it.

## Proposed Solution
SaathiSignal provides a user-controlled support-request workflow that helps users:
- Select counselling, shelter information, or legal aid.
- Choose an approved contact method and safe contact window.
- Route requests to participating support organisations.
- Track acknowledgement and referral status.

## Technology Stack
- Frontend: React.js
- Backend: Python FastAPI
- Database: PostgreSQL
- Security: Authentication, role-based access control, and data minimisation
- Optional AI: Multilingual navigation assistance

## Workflow
User Interface → Consent Validation → Secure Request API → Support-Service Routing → Partner Dashboard → Acknowledgement and Status

## Social Impact
- Reduces barriers to finding appropriate support.
- Promotes informed consent and user autonomy.
- Improves visibility into support requests and referrals.
- Supports coordination among NGOs, counsellors, legal-aid providers, and shelters.

## Feasibility and Safety
The initial prototype can use synthetic data and a simulated partner dashboard. Real-world deployment requires collaboration with qualified support organisations, security testing, and validation.

**Important:** SaathiSignal is a proposed concept. Its effectiveness and safety have not yet been independently validated.
